# Proyecto 3: Python - Daxus

Repositorio correspondiente al tercer proyecto práctico desarrollado bajo la guía y mentoría de **Daxus**. En este proyecto se trabaja en el procesamiento, análisis y visualización de datos de facturación y ventas a partir de fuentes en Excel, generando reportes interactivos y de visualización en HTML.

## 📂 Estructura del Repositorio

El repositorio contiene los siguientes archivos principales:

* **`proyecto3.ipynb`**: Cuaderno de Jupyter principal con el código de procesamiento de datos, análisis de facturación e integración de resultados.
* **`ventas.xlsx` & `Facturacion.xlsx`**: Archivos de datos con la información base de ventas y facturación utilizada para el análisis.
* **Reportes HTML (`.html`)**: Archivos generados con las visualizaciones y desgloses específicos del análisis:
  * `Facturacion.html`
  * `Facturacion por Ciudad.html`
  * `Facturacion por País.html`
  * `Facturacion por tienda.html`
  * `Facturacion por tamaño.html`
  * `Facturacion por local_consumo.html`
* **`README.md`**: Documentación descriptiva del proyecto.

## 🚀 Tecnologías y Herramientas

* **Python** (Pandas, Jupyter Notebook)
* **HTML / Visualización interactiva**
* **Git & GitHub** para el control de versiones
